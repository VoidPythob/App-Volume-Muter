# 应用音量静音控制器 (App Volume Muter)

一个基于 PyQt6 的 Windows 桌面应用程序，用于控制各个应用程序的音量静音状态。支持全局热键统一控制和为每个应用配置独立热键的单独控制模式。

## 功能特性

- **双模式切换**：支持全局模式（一键控制所有启用应用）和单独模式（每个应用独立快捷键）
- **实时音量控制**：基于 Windows Core Audio API (pycaw)，实时读取和设置应用音量
- **全局热键监听**：使用 `keyboard` 库实现系统级热键监听，无需窗口聚焦
- **应用列表管理**：自动扫描当前正在播放音频的应用，支持持久化配置
- **自动保存配置**：在关键操作节点（切换模式、设置热键、勾选应用、静音操作等）自动保存配置
- **可视化状态显示**：表格实时显示各应用的运行状态、静音状态和 PID
- **一键批量操作**：支持一键静音/取消静音所有已启用的应用
- **现代化 UI**：使用 QSS 样式表，界面简洁美观

## 系统要求

- **操作系统**：Windows 10 / Windows 11
- **Python**：3.8 或更高版本

## 依赖安装

```bash
./scripts/install
```

```bash

```
